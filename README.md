# Demystifying the AI Blackbox

The participant form and facilitator findings are static GitHub Pages files in `docs/`. A standalone Cloudflare Worker saves submissions to D1 and serves results only after validating the facilitator key. The key stays in the facilitator's browser memory until they lock or leave the page. It belongs in Cloudflare's secret store. The GitHub repository contains the application and database schema.

## Launch

From `backend/`, sign in to the Cloudflare account that should own the data.

```sh
npx wrangler login
npx wrangler d1 create blackbox-workshop-responses
```

Paste the database ID into `wrangler.jsonc`. Apply the migration, deploy, and set a facilitator key of at least 32 characters. Use a unique random key, such as one generated by a password manager.

```sh
npx wrangler d1 migrations apply blackbox-workshop-responses --remote
npx wrangler deploy
npx wrangler secret put FACILITATOR_KEY
```

Put the deployed HTTPS Worker origin in `docs/config.js`. In the GitHub repository, choose **Settings → Pages → Deploy from a branch → main → /docs**. The participant URL is `https://niclaguerta.github.io/demystifying-the-ai-blackbox/`. Open `results.html` at that address for the facilitator view.

For an account with stored workshop answers, import them into D1 securely before retiring the previous service. Keep any migration exports out of the repository.

## Workshop content

Edit the five prompts in `docs/content.js`. Results include response codes, timestamps, and the five answers. The CSV exports the currently filtered responses.
